# Power BI Executive Sales Dashboard

## Project Overview
An interactive sales dashboard developed using Microsoft Power BI to analyze sales performance and support data-driven decision-making.

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Gross Profit
- Gross Margin
- Total Orders
- Total Quantity Sold

## Dashboard Features
- Month-wise revenue and profit analysis
- Top 5 countries by revenue
- Bottom 5 countries by revenue
- Sales channel revenue comparison
- Product category revenue analysis
- Interactive filters for quarter, month, product category, and country

## Tools Used
- Microsoft Power BI
- Data Visualization
- Business Intelligence
- Data Analysis

## Key Learning
Practiced building interactive dashboards, analyzing business KPIs, and presenting sales insights through visualizations.
